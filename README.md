# 調課代課通知單產生器

自動產製學校「教師調課／代課通知單」與「班級調課／代課通知單」Excel 表格的 GUI 工具。

- **GUI**：Flet（Python，可打包為 Windows exe）
- **產表**：openpyxl
- **參考範例檔**：`115-1手動調代課-兼課.xlsx`

---

## 1. 範例檔分析

### 1.1 檔案層級

範例檔共 **8 個工作表**，每個工作表 = **一個「調代課事件」**（某位老師因公假／請假／調課引發的一連串課務異動）。

| 工作表 | 發起教師 | 事件日期 | 假別 | 假單編號 | 事件型態 |
|---|---|---|---|---|---|
| 範例1 | 曹朱榜 | 民110 | 公假 | 手動+1076 | 兩人對調 |
| 範例2 | 吳建勳 | 民111/1/19 | 公假 | 手動+1279 | 代課 |
| 瑞文1150223 | 余瑞文 | 115/02/23 | 其他 | 手動 | 一對多對調（3 腳） |
| 炆明1150223 | 劉炆明 | 115/02/23 | 其他 | 手動 / 2015+手動 | 對調 + 說明 |
| 若耶1150226 | 陳若耶 | 115/02/26 | 公假 | 2015+手動 | 對調 + 說明（每張都附） |
| 美華1150831 | 朱美華 | 115/08/31 | 其他 | 手動 | 對調（班級單＝橫幅樣式） |
| 瑞文1150831 | 余瑞文 | 115/08/31 | 其他 | 手動 | 對調（班級單＝標題樣式） |
| 炆明1150831 | 劉炆明 | 115/08/31 | 請假 | 手動 | 對調 + 代課混合 + 說明 |

- 工作表名稱格式：`{姓名末兩字}{民國年月日}`，例：余瑞文 → `瑞文` + `1150223`。
- 「範例1／範例2」為空白樣板參考。

### 1.2 每個工作表 = 多張通知單垂直堆疊

一個事件展開為 **三種通知單**，彼此間空 1 列分隔：

#### （A）教師調代課通知單 — 每位被影響的老師各一張

```
列 r    │ A：教師姓名（標楷 18 粗）
        │ B:I 合併 "教 師 調 代 課 通 知 單  假單編號：{編號}  {發起人}  {假別}"（下框線）
列 r+1  │ A："班級"   C："調課後授課時間"（粗）   E:E+1 合併 "授課科目"   G："原授課時間"   I："備註"
列 r+2  │ B"日期" C"星期" D"節次"  │  F"日期" G"星期" H"節次"
列 r+3… │ A：班級 │ B：新日期 C：新星期 D：新節次 │ E：科目 │ F：原日期 G：原星期 H：原節次 │ I：備註
列 末   │ H："公告日期：{民國年}年"（靠右，合併字串）  I："{M月D日}"（靠左）
```

> **公告日期採合併寫法**：`H` 儲存整串 `公告日期：{民國年}年`（靠右），`I` 儲存 `{M月D日}`（靠左），`G` 留空。班級單同。

備註欄文字規則：
| 情境 | 備註 | 特殊 |
|---|---|---|
| 對調 | `與{對方}老師調課` | 新／原時段皆填 |
| 被代課者的單 | `{代課老師}老師 代課` | 「調課後時間」B/C/D 留空 |
| 代課者的單 | `代 {原老師}老師` | 「原時間」F/G/H 留空 |

#### （B）班級調代課通知單 — 每個被影響的班級各一張

本專案 **預設採「橫幅式」**（範例：美華1150831）：

```
列 r    │ A：班級名（標楷 18 粗）
        │ B:I 合併 "教 師 調 代 課 通 知 單  假單編號：{編號}  {發起人}  {假別}"（下框線）
列 r+1  │ B"日期" C"星期" D"節次" E"授課科目" F:I 合併"備註"
列 r+2… │ B：日期 C：星期 D：節次 E：科目 F:I 合併：備註
列 末   │ A："* 請學藝股長公佈。"（粗）  H："公告日期：{民國年}年"（靠右）  I："{M月D日}"（靠左）
```

（保留「標題式」為每事件可切換選項：`A：班級名`、`D：班　級　調　代　課　通　知　單`、`G:I 合併：假單編號：{編號}`。）

班級單備註規則：
| 情境 | 備註 |
|---|---|
| 對調 | `調課(原{原老師}老師/{原科目})` |
| 代課 | `{代課老師}老師 代課` |

#### （C）說明列（選用）

部分事件會在**每一張通知單末端**附一列 `A:I 合併`、列高約 72、自動換行，內容 `說明:\n{一段敘述}`（同一事件所有通知單重複同一段文字）。本專案改為由程式產生草稿、使用者再修改（見 §4）。

### 1.3 事件如何展開成通知單

使用者輸入的最小單位是「**異動腳（leg）**」，程式自動展開：

**對調腳 `SwapLeg`**（甲、乙兩位老師在同一班各拿一節互換）
輸入：`班級, 甲老師, 甲科目, 甲原時段, 乙老師, 乙科目, 乙原時段`
展開 → 甲教師單 +1 列、乙教師單 +1 列、該班級單 +2 列

**代課腳 `SubLeg`**
輸入：`班級, 原老師, 科目, 時段, 代課老師`
展開 → 原教師單 +1 列、代課教師單 +1 列、該班級單 +1 列

規則：
- 同一位老師出現在多個腳 → 該老師教師單累積多列（例：余瑞文 3 列）。
- 同一班級出現在多個腳 → 該班級單累積多列（例：高一甲）。
- 排序：教師單依「首次出現順序」在前，班級單在後（與範例一致）。

### 1.4 一對多情境（多人調課／代課）

「一對多」不是新的資料結構，而是 **一個事件掛多個腳** 的自然結果 —— builder 會依老師／班級把列累積起來：

| 情境 | 表示方式 | 範例 |
|---|---|---|
| 一位老師與多位不同老師分別對調 | 多個 `SwapLeg`，`teacher_a` 相同、`teacher_b` 不同 | 瑞文1150223：余瑞文 ↔ 洪瑞霞／林志嘉／陳凱如（3 班 3 腳）→ 余瑞文教師單 3 列、3 張班級單 |
| 一位老師請假多節、各節由不同人代課 | 多個 `SubLeg`，`orig_teacher` 相同、`sub_teacher` 不同 | 炆明1150831：8/31第4節→徐惠珠、9/2第5、6節→郭惠茹、9/2第7節→黃子玟 |
| 同一班級被多個腳影響 | 多個腳的 `klass` 相同 | 高一甲同時出現在兩個對調腳 → 一張班級單多列 |
| 一節課多位老師共同代課 | 拆成多個 `SubLeg`（同時段、同班、不同 `sub_teacher`） | 罕見；builder 支援，班級單會出現多列 |

**GUI 便利功能（P2）**：提供「批次代課」輸入 —— 選一位請假老師 + 勾多個時段 + 各時段指定代課老師，一次產生多個 `SubLeg`；「批次對調」同理。

**尚未涵蓋（P4）**：「先調後代」串接 —— 發起人先把課調進某時段，該調入時段再請人代課（炆明1150831 的 9/2三567）。目前需拆成獨立的腳手動輸入。

### 1.5 樣式規格

| 項目 | 值 |
|---|---|
| 字型 | 標楷體 12；標題列 標楷體 18 粗體 |
| 欄寬 | A 11.5 / B 9.3 / C 5.5 / D 5.4 / E 14.3 / F 9.3 / G 5.5 / H 6.1 / I 19.7 |
| 列高 | 標題列 25；資料列 20.1；說明列 約 72 |
| 框線 | 全部 thin；橫幅列僅下框線 |
| 日期格式 | `m"月"d"日"`（星期存文字「一…日」；節次存文字） |
| 對齊 | 多數置中；備註靠左＋自動換行；公告年靠右 |
| 版面 | A4 直向、邊界約 0.7 / 0.75、縮放約 95%、列印範圍 `A1:I{最後列}` |
| 民國年 | 西元 − 1911 |
| 星期 | 由日期自動推算，不讓使用者手動填 |
| 節次 | 1–10（含補課／第 8+ 節） |

### 2.3 資料流

```
GUI 表單 ──► Event 物件 ──► builder.build(event) ──► [TeacherSlip…, ClassSlip…]
                                                          │
```

### 2.4 核心資料模型（草案）

```python
@dataclass
class Slot:
    date: datetime.date
    period: str                    # "5"
    # weekday_cn 由 date 自動推算

@dataclass
class SwapLeg:
    klass: str
    teacher_a: str; subject_a: str; slot_a: Slot
    teacher_b: str; subject_b: str; slot_b: Slot

@dataclass
class SubLeg:
    klass: str
    orig_teacher: str; subject: str; slot: Slot
    sub_teacher: str

@dataclass
class Event:
    originator: str                # 橫幅顯示：余瑞文
    leave_type: str                # 公假／病假／事假／請假／其他
    form_no: str                   # 假單編號：單一自由文字，例 "手動+1076"、"2015+手動"、"手動"
    announce_date: datetime.date    # 公告日期
    sheet_date: datetime.date       # 決定分頁名稱的日期（GUI 由使用者選；預設帶最早腳日期）
    note: str = ""                  # 說明（有值就每張單附一列）
    class_slip_style: str = "banner" # banner | title
    legs: list[SwapLeg | SubLeg] = field(default_factory=list)

    @property
    def sheet_name(self) -> str:    # "瑞文1150223"，GUI 可覆寫
```

### 2.5 builder 展開邏輯

```python
def build(event) -> list[Slip]:
    teacher_rows = OrderedDict()   # 老師 → 列（保序）
    class_rows   = OrderedDict()   # 班級 → 列（保序）
    for leg in event.legs:
        if isinstance(leg, SwapLeg):
            teacher_rows[leg.teacher_a] += TeacherRow(new=leg.slot_b, subj=leg.subject_a,
                                            orig=leg.slot_a, note=f"與{leg.teacher_b}老師調課")
            teacher_rows[leg.teacher_b] += TeacherRow(new=leg.slot_a, subj=leg.subject_b,
                                            orig=leg.slot_b, note=f"與{leg.teacher_a}老師調課")
            class_rows[leg.klass] += ClassRow(leg.slot_a, leg.subject_b,
                                            f"調課(原{leg.teacher_a}老師/{leg.subject_a})")
            class_rows[leg.klass] += ClassRow(leg.slot_b, leg.subject_a,
                                            f"調課(原{leg.teacher_b}老師/{leg.subject_b})")
        else:  # SubLeg
            teacher_rows[leg.orig_teacher] += TeacherRow(new=None, subj=leg.subject,
                                            orig=leg.slot, note=f"{leg.sub_teacher}老師 代課")
            teacher_rows[leg.sub_teacher]  += TeacherRow(new=leg.slot, subj=leg.subject,
                                            orig=None, note=f"代 {leg.orig_teacher}老師")
            class_rows[leg.klass] += ClassRow(leg.slot, leg.subject,
                                            f"{leg.sub_teacher}老師 代課")
    return [TeacherSlip(n, r) for n, r in teacher_rows.items()] + \
           [ClassSlip(k, r)   for k, r in class_rows.items()]
```

## 3. 輸出行為（單鍵、雙動作可同時）

GUI 有 **一顆「產生通知單」按鈕**，上方有兩個可各自勾選的目標：

- ☑ **寫入總表** — 開啟指定的總表 `.xlsx`；若已存在同名工作表則刪除重建；存回原檔。
  - 總表路徑於設定中選擇並記住（預設＝上次使用）。
- ☑ **另存新檔** — 產生只含該事件工作表的新 `.xlsx`。
  - 預設檔名 `{分頁名稱}.xlsx`，位置與總表同資料夾，可於存檔對話框更改。

按一次按鈕 → 依勾選的目標**一次完成**（可兩者皆做），結束顯示結果摘要（各檔路徑、寫入列數、是否覆蓋舊工作表）。至少需勾選一項才可執行。

## 4. 「說明」草稿產生規則

`note_draft.py` 依事件的腳產生一段可編輯草稿：

1. 將對調腳依「互換的兩組時段」彙整：
   `{日期A}({星期A})第{節次們A}節課務與{日期B}({星期B})第{節次們B}節課務互調`
2. 每位對方老師 → `，故{發起人}老師{原時段}調至{新時段}上課`
3. 代課腳 → `，{時段}由{代課老師}老師代課`

範例輸出（對照 炆明1150831）：

```
說明:
8/31(一)第1、2、3節課務與9/2(三)第5、6、7節課務互調，
故劉炆明老師8/31(一)第1、2、3節調至9/2(三)第5、6、7節上課；
9/2(三)第5、6節由郭惠茹老師代課、9/2(三)第7節由黃子玟老師代課、
8/31(一)第4節由徐惠珠老師代課。
```

草稿不求完美，使用者於 GUI 多行框微調；留空則不產生說明列。

### GUI（P2，可用）

```bash
python main.py
```

畫面：左側事件清單（新增／複製／刪除），右側編輯區——事件資料、說明（可一鍵產生草稿）、
調課／代課腳、即時預覽、輸出區（勾選「寫入總表」與／或「另存新檔」後按「產生通知單」，

> 於 flet 0.86.5 開發；GUI 視覺細節（欄寬、換行、捲動）需在桌面實機再微調。

資料庫：左側進階的「資料庫 .json」欄預設指向 `%APPDATA%\tiaoke\調代課資料庫.json`，
開程式時若存在就自動載入。按〔儲存〕會把本次的調代課單**併進**這個資料庫
（依分頁名稱：不存在→新增、內容有改→更新、完全一樣→略過），同時輸出一份 `.xlsx`。
設定與最近檔案存於 `%APPDATA%\tiaoke\settings.json`。

**匯入課表**（左側進階）：貼上「教師課表 PDF」路徑 →〔讀取〕→ 解析後問要不要存成
`課表.json`（存檔並套用／只套用不存）。之後在調課／代課表單填了「老師＋日期」，
會列出該老師當天的課，點一下就帶入科目／班級／節次；例外仍可手動填。
課表 JSON 內含 老師姓名・編號・職稱、每筆課的 星期／節次／科目／班級／地點（領域此 PDF 無）。
